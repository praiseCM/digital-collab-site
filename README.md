# Digital Collaboration Research

Source code for the interactive research website:

https://digital-collab.drlong.us

The website presents research on digital collaboration in construction project management, including the Network-Extended Theory of Planned Behavior (NE-TPB), research findings, and an interactive literature landscape.

## Research repository

Data, analysis code, supplemental analyses, and reproducibility materials associated with the research are maintained separately at:
